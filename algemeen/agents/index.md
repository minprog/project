## Agentic coding pilot

Coding agents zoals Claude, Codex en Copilot veranderen veel in hoe mensen software bouwen. Zo'n agent heeft in zich een combinatie van een model (een LLM) en een harnas (een verzameling aan tools en instructies). Zie het model als het brein en het harnas als manieren om te interacteren. Door zo'n harnas kan een model bijvoorbeeld je bestanden lezen en aanpassen, maar ook bijvoorbeeld programma's uitvoeren, je browser openen en besturen. Daarbovenop zit dan een agent loop, een herhaling van instructies aan het model. Daardoor kan een LLM ineens een stuk meer dan alleen tekst genereren: het kan hele plannen uitwerken, testen en itereren.

### Afweging

De situatie is niet helemaal rooskleurig. Perfect zijn agents zeker niet en het is maar de vraag of programmeren met agents leuk(er) is. In feite laat je een machine los op jouw werk en zo'n agent kan snel veel veranderen en heel veel code toevoegen. Zo kan het allemaal een zootje worden, maar ook het gevoel van controle en eigenaarschap van je code wegnemen. Daarnaast is programmeren leuk omdat je moeilijke problemen tegenkomt en oplost, en dat gevoel verwatert met een agent.

Daar staat tegenover dat agents je snel laten itereren. Features die anders dagen kosten gaan in uren of zelfs minuten. Je kan daardoor zelf meer energie steken in hoe je jouw applicatie wil laten werken, hoe het moet voelen, hoe het eruit moet zien. Het wordt allemaal sneller echt en je applicatie komt verder in minder tijd.

### Keuze

Je mag er voor kiezen om met een coding agent te werken voor jouw eigen project. Je mag er ook voor kiezen om dat niet te doen, of het alleen uit te proberen. Er zijn ook allerlei vormen waarin je een agent kan inzetten: van het uitwerken van een deel van een kleine functie tot een deel van je project. Maar denk ook bijvoorbeeld aan het reviewen en structureren van je code.

Wij zijn hoe dan ook super benieuwd naar wat en hoe je leert werken met een agent. Dus verwacht gedurende het vak een boel vragen!

### Hoe? (model)

Het zal je niet zijn ontgaan: AI is duur. Zeker coding agents vreten tokens en degelijke modellen zijn niet op kleine hardware (laptops) te draaien. Dan kom je al snel aan bij grotere Amerikaanse bedrijven waar je of een abonnement moet afsluiten (met limieten) of anders (flink) betaalt voor gebruik.

Gelukkig kan je als student via de UvA toegang krijgen tot verschillende modellen. Deze worden o.a. gehost bij SURF. Dat betekent dat je data niet overzees gaat en niet wordt gebruikt voor andere doeleinden. Let wel, stuur nog steeds geen gevoelige informatie. Om toegang te krijgen heb je een API-key nodig. Deze krijg je gedurende het vak van ons via de mail.

Die API-key heeft een zeer klein budget en dat is niet genoeg om een heel project mee neer te zetten. Maar, één model (Qwen 3.6) is ongelimiteerd en gratis in gebruik. Qwen 3.6 kan je dus gedurende het vak gebruiken. Zo hoef je niks te betalen en ook niet te wachten tot een limiet reset.
